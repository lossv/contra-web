# 魂斗罗 · 铁血突击

可直接玩的单人魂斗罗风格网页游戏，使用原创 Canvas 像素场景、角色和 Web Audio 合成音效，不含原版 ROM、音乐或图像素材。这是三关同人演绎，关卡布局与数值不是原版逐像素复刻。

## 三关

1. **丛林突袭**：4600 像素横向战场、平台和断桥、巡逻兵、炮台、无人机，关底前线堡垒。
2. **基地攻坚**：纵深透视射击，三间防御室及第四间核心 Boss 房；左右移动对准前方目标，卧倒避弹。
3. **瀑布要塞**：2520 像素纵向攀登，28 级中间跳台、炮台与武器补给，山顶钢铁巨兽 Boss。

包含连续战役、各关练习、休闲 5 命/经典 3 命、散弹 S/连射 M/激光 L/护盾 B、复活检查点、计分与本地最高分、暂停、失焦自动暂停、触屏按键、声音开关和浏览器全屏。

## 操作

- 方向键或 WASD：移动、向上瞄准、卧倒；空中可以向下射击。
- Z / J：按住射击。
- X / K / 空格：跳跃。
- P / Esc：暂停或继续；M：静音；Enter：开始或继续。
- 手机和平板使用画面下方触屏方向键与 A/B 按钮，支持多指同时移动和射击。

## 运行

Node.js 22.13+。

```sh
npm install
npm run dev
npm test
npx tsc --noEmit
npm run build
```

`app/game.ts` 是固定 60 Hz 模拟的独立游戏引擎，`app/page.tsx` 提供界面和触屏操作，`app/globals.css` 提供响应式样式。

## 验证

`npm test` 使用模拟 Canvas/浏览器宿主，覆盖三关初始化、重力与跳跃、移动及连射、武器弹道、死亡与无敌保护、掉落复活、暂停、基地逐室推进、三场 Boss 伤害与通关衔接、完整瀑布攀登输入，以及 WebMCP 注册和有效/无效输入契约，共 38 项检查。瀑布全程检查通过真实逐帧移动和跳跃输入完成。

已进行 TypeScript 检查和生产构建。没有执行浏览器视觉或真人试玩验证；WebMCP 契约在模拟宿主中验证，尚未在支持该提案的实际浏览器宿主中验证。WebMCP 支持通过 `document.modelContext` 检测，未支持的浏览器仍能正常游戏。
